Free setup instructions (about 10–20 minutes)
  1. Create a free project at supabase.com.
  2. In its SQL Editor, run the SQL shown below. It creates a private sales-data table secured to your email-authenticated account.
  3. In Project Settings / API, copy the project URL and publishable / anon key into the fields above. Never enter a secret or service-role key.
  4. In Authentication → URL Configuration, configure the URL where you publish this tracker as an allowed redirect URL. For testing from a file, use a hosted HTTPS site instead.
  5. Host this HTML for free on GitHub Pages or Netlify. Open that exact hosted URL on both devices, enter the same project settings and email, and click Email sign-in link.
  6. Once signed in, your changes sync automatically after a short delay when online. Use Sync now after switching devices and download backups regularly.
create table if not exists public.fieldline_data (
  user_id uuid primary key references auth.users(id) on delete cascade,
  payload jsonb not null default '{}'::jsonb,
  updated_at timestamptz not null default now()
);
alter table public.fieldline_data enable row level security;
create policy "read own" on public.fieldline_data
  for select to authenticated using ((select auth.uid()) = user_id);
create policy "insert own" on public.fieldline_data
  for insert to authenticated with check ((select auth.uid()) = user_id);
create policy "update own" on public.fieldline_data
  for update to authenticated using ((select auth.uid()) = user_id)
  with check ((select auth.uid()) = user_id);
Important: Sync is last-write-wins for changes made on two devices at the same time. Finish and sync entries on one device before editing on another. The free provider may impose usage limits.

Backups and export

Download a backup weekly. Your CSV includes daily raw counts and calculated metrics. JSON backup preserves settings, notes, and all days. Restoring replaces the currently saved data on this device.
